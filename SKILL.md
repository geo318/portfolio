# Skill: Giorgi Portfolio App

Use this when working inside this repository.

## Mission

Maintain Giorgi Lomidze’s 3D-focused frontend portfolio. Preserve the blueprint/CAD lab aesthetic and honest technical positioning.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Three.js / React Three Fiber / Drei
- Zustand
- Zod

## Workflow

1. Read `AGENTS.md`, `INSTRUCTIONS.md`, and `IMPLEMENTATION.md`.
2. Inspect `src/content/portfolio.ts` before editing copy/cards.
3. For layout work, inspect matching file in `src/components/sections`.
4. For scan mode, inspect `src/features/scan-mode`.
5. For 3D work, inspect `src/features/three-lab`.
6. Run `npm run lint` and `npm run build`.

## Non-negotiables

- Keep design technical, spatial, and blueprint-like.
- Keep claims truthful.
- Do not present the Three.js scene as long production experience.
- Keep 3D lazy-loaded and fallback-friendly.
- Do not add heavy dependencies without clear need.
